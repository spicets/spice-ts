# @spice-ts/mcp

## 0.4.0

### Minor Changes

- d9cd81a: Enforce a per-server concurrent running-job quota (`streaming.maxConcurrentJobs`, default 2) shared by `spice_simulation_start` and `spice_simulate`; calls beyond it fail with a retryable structured `RESOURCE_LIMIT` (`details.limit: "maxConcurrentJobs"`, `configured`/`observed`, `maximum`/`actual`). The terminal-job retention TTL is now 300000 ms (was 60000 ms). `spice_capabilities` reports the quota, and the defaults now match docs/architecture/ai-native-api.md section 8 (#792).
- 5a03da9: Add finite, case-insensitive top-level `.param` overrides to `spice_simulate` and `spice_simulation_start`, with capability discovery and structured `UNKNOWN_PARAMETER` errors listing available names.
- 965334c: Return solver-free advisory topology warnings from spice_validate with node and element ids and repair hints. Keep simulation and default direct-core validation behavior unchanged.

### Patch Changes

- 1841917: Stream jobs that are not forwarded live (OP/DC analyses, mixed analyses, `spice-ts` JSON input, or an injected `simulate`) no longer fail with `RESOURCE_LIMIT` (`maxUnreadEvents`/`maxUnreadBytes`) when the finished result has more than 256 events. The finished result, already bounded by `maxResultPoints`/`maxSerializedResultBytes`, is now converted to events lazily and released in cap-sized batches as reads drain the unread window, the same backpressure live jobs get. Cursor replay is unchanged, and an event that alone exceeds the unread caps still fails the job (#794).
- 33c8c64: Allow scalar measurements to select a zero-based parameter step, report available step counts for ambiguous analyses, and return UNKNOWN_STEP for unavailable selections.
- 037edce: Transient Newton failures now follow ngspice-47 (#804). A timepoint fails after 100 Newton iterations by default, not 50. This is the niiter.c NIiter floor that ngspice applies to its default ITL4 = 10. A non-converged timepoint is now retried at order 1 (Backward Euler), with the step cut by 8, as in dctran.c (`CKTorder = 1`). Before, it kept trapezoidal history. On corpus-h mosamp2.cir (MOS LEVEL=2), the step sequence now stays closer to ngspice's across the fast edge, and the residual drops from 1.61% to 0.63%. Decks that fail Newton often now cost more iterations per failed attempt, as in ngspice. The MCP resolved-options default for `maxTransientIterations` now reports 100.
