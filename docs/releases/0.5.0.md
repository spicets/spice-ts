# spice-ts 0.5.0 release candidate

These notes describe the next candidate, not a published release. Package
versions remain unchanged here. Mattia owns versioning, publication and tags.

## Protocol moves into core

`@spice-ts/protocol@0.3.0` is superseded by `@spice-ts/core/protocol`.
Change imports to the new subpath. Protocol v1 types, schemas, conformance
checks and canonical JSON/SHA-256 functions are unchanged. Both ESM and
CommonJS entry points remain available. JSON documents move to
`@spice-ts/core/protocol/schemas/*` and `@spice-ts/core/protocol/fixtures/*`.
The subpath remains environment-neutral and does not import the simulator.

MCP and the private WASM package now consume the core subpath. The published
package set is reduced to four: core, MCP, UI and circuit-json. Core's optional
`eecircuit-engine` peer is unchanged.

The old npm protocol package remains available; do not unpublish it. After
this release, Mattia runs
`npm deprecate @spice-ts/protocol "moved to @spice-ts/core/protocol"`
with npm 2FA. This PR does not run that command or publish any packages.
