## Method

- ngspice: `unchanged corpus-f runNgspicePacked on original bytes`. Status success means exit 0 and at least one op/dc/ac/tran/pz/noise/disto plot in the raw file; failed/unsupported is classified from ngspice's own output.
- spice-ts: `unchanged corpus-f runBoundedSimulatePacked on original bytes`. The runner and metric are corpus-f's (`benchmarks/corpus/corpus-f/{outcomes,lib}.ts`), imported unchanged. Gap buckets reuse corpus-l/i/h/f error classes unchanged.
- matched = both engines succeed, every spice-ts analysis has an ngspice counterpart, and for every common signal max|spice-ts - ngspice| <= 0.01 x max(peak |ngspice signal|, floor). The floor is uniform per quantity (#593): 0.0001 V for node voltages v(...) and 1e-10 A for branch currents i(...), so a signal whose ngspice peak is zero or tiny matches when the absolute difference is at most the ngspice-47 default VNTOL (0.000001 V) or ABSTOL (1e-12 A); every other quantity (pole/zero roots, noise spectra) keeps 1e-12. Deck .options tolerances are not consulted. Errors are taken at spice-ts points with ngspice interpolated (transient breakpoint alignment as in the aggregate report).
- "worst" is that normalised error for the worst signal.
- Bounds: uniform 119 s owned engine process-group deadline. The outcome hash excludes environment, tools.node, ngspice.analyses, spiceTs.analyses.
- Regenerate: `spice-heavy pnpm exec tsx benchmarks/corpus/corpus-n/parity.ts`; verify without writing: `pnpm exec tsx --test benchmarks/corpus/corpus-n/corpus-n.test.ts`.
- Machine: darwin 27.0.0 arm64, Apple M5 Pro; Node v22.23.1.
